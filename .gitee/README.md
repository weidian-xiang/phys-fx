# Gitee 社区文件

这里存放 Gitee 主仓使用的 Issue、PR 模板。Gitee 是 PhysFX 的唯一主仓库，GitHub
（`https://github.com/weidian-xiang/phys-fx`）仅作为只读镜像。

外部贡献者应在 Gitee 创建 Issue/PR，不能直接推送 `master`；仓库所有者/主维护者可将
本人代码直接推送到 `master`。镜像由 Gitee 单向推送到 GitHub，不配置反向同步。完整的
权限、远程命名、镜像配置和故障处理见 [`docs/git-workflow.md`](../docs/git-workflow.md)
与 [`docs/mirror-sync.md`](../docs/mirror-sync.md)。
