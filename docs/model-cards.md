# 模型卡片

Phase 3 的模型权重不入库，下载到被 `.gitignore` 忽略的 `models/`。每个模型在
落地前必须记录来源、版本、SHA256、转换方式和再分发许可。

| 模型角色 | 候选 | 当前状态 | 许可/再分发 |
| --- | --- | --- | --- |
| 首帧分割 | SAM 类 ONNX 导出 | 接口预留，未随仓库分发 | 以原始模型许可为准 |
| 时序跟踪 | XMem 类 ONNX 导出 | 接口预留，未随仓库分发 | 以原始模型许可为准 |

使用 `tools/download_models.py --url <地址> --sha256 <哈希>` 下载。没有权重时，
`needs_models` 测试必须跳过而不是失败。未经许可审查不得把权重、转换脚本或模型
输出样例提交到仓库。
