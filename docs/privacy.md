# 云端隐私政策（Phase 6）

这是单机参考服务的强制行为契约，正式公网服务上线前必须由维护者和法律顾问复核。

1. 用户视频传输必须使用 HTTPS；任务输入只保留到任务完成后取回所需时间，默认最长 24 小时，过期由 `DELETE /v1/privacy/expired` 清理。用户可在任务页即时删除。
2. 用户素材不用于训练模型，不用于内容分析之外的用途，也不出售给第三方。
3. 遥测默认关闭；开启时仅记录匿名功能计数，并在 GUI 首次进入云端入口前展示开关和隐私条款。
4. API Key 只保存哈希；任务容器与 API 隔离，下载链接应短时有效并写入访问日志。

参考服务目前使用本地 SQLite 和对象目录，不代表已完成公网 HTTPS、容器沙箱或合规审查；这些是开放云服务前的硬门槛。
