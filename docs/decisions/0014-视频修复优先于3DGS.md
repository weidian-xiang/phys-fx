# ADR-0014：视频修复优先于 3DGS

## 状态

已接受（Phase 4）。编号顺延：仓库已有 Phase 3 的 ADR-0010，本决策使用下一个可用编号。

## 决策

Phase 4 先建设分割、跟踪、视频修复和分层合成，3DGS/NeRF 物体级重建推迟到 Phase 5。
任意实拍视频的鲁棒性、分钟级出片承诺和修复/移动能力的资产复用优先于高成本的场景重建。

## 边界

本阶段的 `InpaintingRenderer` 提供确定性的 CPU 基线；真实 ProPainter/E2FGVI 类 ONNX
适配器仍需模型卡和质量验收，不能把基线结果宣称为神经修复质量。
