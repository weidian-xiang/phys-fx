# ADR-0006：依赖引入与许可合规

## 状态

已接受（Phase 3）。

## 决策

FFmpeg 只允许使用不启用 GPL 组件的 LGPL-2.1+ 共享构建，并通过动态链接接入；
ONNX Runtime 使用 MIT 许可官方预编译包。实体包和模型权重不入库，由脚本按锁定
版本下载并校验。

## 影响

默认 CMake 配置保持 `PHYSFX_WITH_FFMPEG=OFF`、`PHYSFX_WITH_ONNX=OFF`，无实体依赖
时仍可构建。启用选项而找不到合规开发包时，配置阶段给出中文警告并回退桩实现。
NOTICE 与第三方版本表记录归属和获取路径；不得用本机 GPL 静态 FFmpeg 作为发布依赖。
