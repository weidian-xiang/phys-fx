# ADR 0002：整合语义编辑域

## 背景

仅有物理特效无法表达“选中物体、换材质、改变天气”等视频世界编辑操作。

## 决策

新增 `semantics`、`editing`、`neural_render` 三个同级能力域；语义实体契约放在 `core::SemanticScene`，编辑命令只作用于契约，不依赖语义算法实现；两类渲染路径通过 `core::IRenderPath` 统一出口。

## 影响

Pipeline 从三阶段升级为五阶段，Phase 1 的 `Frame`、`SceneContext`、`SimulationResult` 字段语义不变，仅增加默认字段。
