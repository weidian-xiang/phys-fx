# ADR-0020：3DGS 方向终局门槛

## 状态

已拒绝（Phase 8 终局收尾，2026-08-21）。

## 决策

Phase 6 设定的真实数据、许可和交互帧率门槛在 Phase 7 结束前没有形成可复核的完整证据链，
因此按原终局条款停止 3D Gaussian Splatting 自由视角路线。v1.0 和 1.x 不把 3DGS 作为
产品能力、商业卖点或隐含路线，继续采用已经可测试的 2.5D 分层编辑、语义遮挡和传统降级。

此结论是执行既有门槛，不是重新评估。后续出现新想法只能进入独立 ADR，不能修改 v1.0
冻结清单，也不能把研究 spike 合入 `master`。
