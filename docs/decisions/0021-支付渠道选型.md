# ADR-0021：Stripe 沙箱先行，支付默认关闭

## 状态

已接受（Phase 7 技术实现）；现实世界经营主体、商户号和税务资质仍待用户完成审批。

## 决策

技术侧先接 Stripe-compatible Webhook 适配层与沙箱流程。国内微信支付/支付宝保留同一
`PaymentProvider` 边界，待主体资质完成后再接入，不把任何密钥或商户凭据提交到仓库。

`PHYSFX_BILLING_ENABLED` 默认 `0`。关闭时价格查询可见但下单、Webhook 和退款均拒绝，云
渲染继续使用 Phase 6 免费行为。开启后仍只允许沙箱或已审批环境显式配置。

## 不变量

- 订单、订阅、流水、Webhook 事件和退款均落库。
- `Idempotency-Key` 按用户唯一；Webhook `event_id` 全局唯一。
- 支付成功只增加当前周期配额；人工退款写冲正流水，不自动发起外部退款。
- 价格页必须标注“以实际开通为准”，不构成经营主体资质或支付开通承诺。
