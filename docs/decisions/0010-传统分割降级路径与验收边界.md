# ADR-0010：传统分割降级路径与验收边界

## 状态

已接受（Phase 3）。

## 背景

SAM/XMem 权重的具体 ONNX 导出、输入输出名称和再分发许可尚未锁定。把未审查权重
直接写进自动下载脚本会破坏依赖治理，也不能用语义桩冒充真实模型效果。

## 决策

保留 `OnnxSegmenter`/`OnnxTracker` 的可选运行时装载路径，并新增零依赖的
`ColorPromptSegmenter` 与 `CentroidTracker`。前者从配置提示点读取种子颜色，以四连通
区域生长产生真实像素掩码；后者合并掩码时序并计算实体质心轨迹。端到端示例默认
使用该传统路径，模型就位后只替换工厂配置，不修改管线上层。

## 边界

传统路径只证明视频 IO、语义契约、粒子绑定和遮挡合成能够端到端协作，不宣称达到
SAM/XMem 的泛化质量。`v0.2.0` 的模型性能和 720p 时序质量仍须在经许可锁定的权重
到位后补测；无权重的 `needs_models` 用例明确标记为跳过。
