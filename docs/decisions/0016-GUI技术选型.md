# ADR-0016：节点式 GUI 技术选型

## 状态

已接受（Phase 5，分层落地）。

## 决策

GUI 数据层采用 C++20 自有 `Project`/`ProjectCompiler`，节点图只支持线性/浅层编排，
工程保存为 `.physfxproj` JSON，并将节点命令编译为 Phase 4 编辑脚本。窗口后端保持可选，
通过 `PHYSFX_BUILD_GUI` 裁剪，GUI 单向依赖 `pipeline`，核心不反向依赖 GUI。

Dear ImGui + imnodes/OpenGL 是后续窗口后端的首选；本阶段先完成可测试的数据契约，避免
把重型 GUI 依赖引入核心构建。Qt 仍是备选，不在本阶段引入。
