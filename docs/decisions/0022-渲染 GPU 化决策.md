# ADR-0022：GPU 只作为可选合成路径，CPU 保持数值基线

## 状态

评估完成，Phase 7 落地 provider 探测与预览分层；精灵/密度场 GPU compute 暂不默认启用。

## 决策

ONNX Runtime provider 顺序为 CUDA → DirectML → CPU，初始化失败自动回到 CPU，并公开实际
provider 名称。合成器继续使用既有 CPU 实现作为可重复基线；无 GPU runner 或驱动白名单时
不输出 GPU 性能数字。后续 OpenGL compute 试点必须提供双路径像素等价测试、驱动白名单和
独立性能证据后才可成为默认路径。

## 原因

当前冻结模型没有可验收的输入输出合同，GPU 化不能把永久模型限制包装成商业 SLA；CPU 数值
稳定性和既有断言优先于未经证据验证的吞吐提升。
