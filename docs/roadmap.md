# 路线图

| 阶段 | 内容 | 状态 |
| --- | --- | --- |
| Phase 1 | 架构骨架、接口、空管线 | ✅ 已完成 |
| Phase 2 | 语义编辑域整合、架构优化、版权确权、Git/Gitee 开源启动、商业化接口预埋 | ✅ 已完成 |
| Phase 3 | FFmpeg 视频 IO、分割跟踪、简单粒子合成、CI | ✅ `v0.2.0` |
| Phase 4 | 编辑命令与脚本、删除/移动 CPU 基线、Taichi 进程桥、三条模板 CLI | ✅ `v0.3.0` |
| Phase 5 | 节点工程、深度/天空/光照、泼水/爆炸/换季节模板、模板签名 | ✅ `v0.4.0` |
| Phase 6/6.1 | 本地云/市场、真实 GUI、Taichi 验收、同步门禁与终局限制 | ✅ `v0.5.0` |
| Phase 7 | 支付与订阅、GPU 管线、企业私有部署、分成结算、关键帧曲线与 3DGS | 未启动 |

Phase 3 的原则是可选实体依赖、默认零依赖可构建；不能把未获取的模型或 LGPL 动态包
冒充真实算法验收。当前已验证能力是 LGPL FFmpeg 真实读写、提示点颜色连通分割、
质心跟踪、CPU 粒子、密度场和语义掩码遮挡链路。SAM/XMem/ProPainter/Depth Anything
永久按 `docs/model-cards.md` 的终局限制处理，不宣称神经推理质量。

Phase 6 的商业入口采用本地优先原则：单机云服务参考实现提供 API Key、队列、配额计数、
模板索引和限时任务记录，但未连接支付或对象存储托管。真实窗口和外部 Taichi 已验收；
模型采用永久白名单降级，因此云渲染与市场保持默认关闭，不对外作神经质量承诺。

## Phase 7 粗规划

- 商业化：支付/订阅、配额扣费、企业批量与私有部署。
- 性能：GPU 推理默认路径、渲染管线 GPU 化、云端水平扩展。
- 编辑：换材质完整版、关键帧曲线编辑器，3DGS 失败则深化 2.5D 分层编辑。
- 生态：第三方模板作者入驻与分成结算、插件 SDK 和社区贡献者流程。
- 传播：英文界面/文档、国际镜像和更完整 demo 矩阵。
