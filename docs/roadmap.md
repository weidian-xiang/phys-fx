Phase 3 的原则是可选实体依赖、默认零依赖可构建；不能把未获取的模型或 LGPL 动态包
冒充真实算法验收。当前已验证能力是 LGPL FFmpeg 真实读写、提示点颜色连通分割、
质心跟踪、CPU 粒子、密度场和语义掩码遮挡链路。SAM/XMem/ProPainter/Depth Anything
永久按 `docs/model-cards.md` 的终局限制处理，不宣称神经推理质量。

Phase 6 的商业入口采用本地优先原则：单机云服务参考实现提供 API Key、队列、配额计数、
模板索引和限时任务记录，但未连接支付或对象存储托管。真实窗口和外部 Taichi 已验收；
模型采用永久白名单降级，因此云渲染与市场保持默认关闭，不对外作神经质量承诺。

## Phase 7 已交付

- JSON 解析器资源上限、编辑脚本/工程文件结构化校验、fuzz 语料和 nightly ASAN/UBSAN。
- Stripe-compatible 支付沙箱、订单/订阅/流水、Webhook 幂等、对账和人工退款冲正；默认关闭。
- CUDA → DirectML → CPU provider 探测，GUI 曲线编辑和半分辨率快速预览状态机。
- 插件 SDK、Good First Issue 贡献入口、核心英文文档和质量/崩溃隐私说明。

## Phase 8 交付与遗留

- 开工基线、支付状态和外部物料缺口已如实登记；`MATERIAL_STATUS` 仍为 `pending`。
- `docs/v1-freeze.md`、`docs/compatibility.md`、公共 API 审计与门禁已入库；冻结清单文件仍保留
  “待维护者确认”状态，Phase 9 不擅自改写确认记录。
- 3DGS 按 ADR-0020 原门槛终局拒绝；扩散式编辑仍只允许 ADR 研究，不进入 v1.0。
- Gitee `v0.6.0` Release 正文、GitHub 同名 Release、真实演示物料、RC 和正式版均未完成，
  统一转入 Phase 9 串行清零。

## Phase 9 当前状态

- `docs/phase9-kickoff-report.md` 已登记远端、CI、Release、支付和物料门禁的可复核状态。
- 当前停留在任务①：Gitee `v0.6.0` 正文待修，GitHub `v0.6.0` Release 待补建。
- `docs/model-lock.json` 的四个模型仍无 URL、revision 或 SHA-256，真实模型任务未启动。
- 三类实拍素材尚无完整授权集合；私人本地文件不会被推定为可使用或可发布。
- Phase 9 只执行基线清零、真实效果、演示复现和 `v1.0.0` 发布，不开启其他方向。
