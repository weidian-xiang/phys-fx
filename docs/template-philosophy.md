# 模板哲学：把复杂封装成可理解的操作

物理模拟、语义分割、时序跟踪和神经渲染对开发者很复杂，对普通创作者也同样复杂。PhysFX 的产品策略是将完整能力栈留给开发者，将常见目标封装为模板：

- “换车色”：语义选择实体 → `ChangeMaterial` → 重新渲染；
- “一键换季节”：`SetWeather`、`SetTimeOfDay` 与渲染参数组合；
- “实拍视频加火焰”：物理模板调用粒子模拟、地面平面、遮挡和色彩匹配。

模板不是核心算法的替代品，而是插件层对命令、参数和渲染路径的可复用封装。所有编辑意图仍表达为可序列化 `IEditCommand`，因此 GUI、批处理、云协作和撤销/重做共享同一语义。
