# Phase 9 演示素材登记

本目录中的 MP4 原始素材不纳入 Git。它们仅用于 Phase 9 任务②的本地管线验证，不能在
发布物料中表述为实拍素材。

## 来源

- 生成工具/来源：HappyHorse-1.1-T2V
- 素材性质：AI 生成测试素材，容器带有 `AIGC Label=1` 元数据
- 生成提示词：未随本次素材提供，当前无法从 MP4 元数据恢复；不得由项目维护者或 Agent 推断
- 许可/发布授权：仅按维护者提供的本地任务输入使用；未形成外部传播授权记录

## 使用边界

三段素材可以用于验证编解码、模型输入、去物/移动/特效管线，以及维护者本地肉眼检查。
它们不能单独满足 Phase 9“真实 720p 实拍素材”核心完工判据，不能作为实拍发布视频、
真实模型质量基线或公开 Release 附件。发布台账中的对应项必须保留这一限制。
